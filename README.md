# Математические игры, 5 класс

9 обучающих игр по математике для коррекционной школы (учебник М. Н. Перовой, с. 3–70). Каждая игра рассчитана на урок 40 минут: правило с озвучкой, закрепление, задания, блиц и финальная битва.

1. [Тайна пиратского клада](pirates.html) — Сложение и вычитание в пределах 100 с переходом через десяток (с. 3–26)
2. [Детективное агентство «Икс»](detective.html) — Нахождение неизвестного слагаемого (с. 11–15)
3. [Замок Дракона](dragon-castle.html) — Нахождение неизвестного уменьшаемого и вычитаемого (с. 15–26)
4. [Город Строителей](geometry-city.html) — Линии, отрезок, луч, ломаная, углы, фигуры (с. 27–33)
5. [Подводная экспедиция](ocean-numbers.html) — Нумерация до 1000: сотни, разряды, нули (с. 34–43)
6. [Покорители вершин](rounding-mountains.html) — Округление до десятков и сотен (с. 43–45)
7. [Тайны Древнего Рима](roman-numerals.html) — Римская нумерация: I, V, X (с. 45–46)
8. [Весёлая ярмарка](measures-fair.html) — Меры стоимости, длины и массы (с. 46–53)
9. [Гонка Чемпионов](race-1000.html) — Сложение и вычитание в пределах 1000 (с. 54–70)
